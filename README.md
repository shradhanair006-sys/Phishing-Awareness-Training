# 🛡️ Phishing Awareness Training Website

## 📌 About the Project
The Phishing Awareness Training Website is an interactive educational platform designed to help users understand phishing attacks, recognize suspicious emails and websites, and improve their cybersecurity awareness.

## ✨ Features
- Information about phishing attacks.
- Tips to identify phishing emails.
- Common social engineering techniques.
- Safety tips to prevent phishing attacks.
- Interactive phishing awareness quiz.
- Phishing Email Detection Challenge.
- Responsive and user-friendly interface.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🚀 How to Run the Project
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Explore the website and test the interactive features.
